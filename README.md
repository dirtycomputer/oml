# OML · Open Meta-Life

OML v0.1 是一个可审计的跨文化人格实验：用 144 道原创双向条目形成 12 个连续维度，并将出生信息转换为一个可关闭、最高只占 15% 的文化象征层。

在线版本：<https://oml-sepia.vercel.app/>

## 已实现

- 144 题候选标准问卷：12 维 × 每维 12 题，正反向各 6 题；固定交错顺序。
- 12 维 0—100 计分、响应质量提示、雷达图与 `SPLO-S` 形式的 OML 代码。
- 出生信息算法：近似太阳黄经、太阳星座、月相、四柱干支、五行／阴阳、生命路径数。
- 八字／西方星盘／MBTI／大五的统一概念映射表。
- 不使用性别或性取向推断的伴侣匹配算法；另行纳入双方主动声明的沟通与关系结构偏好。
- 34 个代表性传统与现代体系的全球社会影响力排序，并把影响力与科学证据分开标注。
- 全部计算在浏览器本地完成；没有后端，也不上传出生信息或答卷。

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173/`。

```bash
node tests.mjs
```

## 文件

- `oml-core.js`：题库、维度、排名数据与全部纯计算函数。
- `app.js`：问卷、报告、匹配器、图谱和本地状态交互。
- `index.html` / `styles.css`：无构建依赖的静态界面。
- `METHODOLOGY.md`：公式、假设、文化边界与验证路线。
- `vercel.json`：生产托管与安全响应头配置。
- `.github/workflows/ci.yml`：每次推送后复核算法不变量。

## 重要边界

OML v0.1 尚未经过代表性常模、重测信度、测量不变性或预测效度研究。传统命理与出生象征层不应被解释为科学预测。它不能用于医疗或心理诊断、招聘、教育筛选、信贷、保险、司法、移民、监控或决定一段关系是否安全。

MBTI 是 The Myers-Briggs Company 及其关联权利人的商标。本项目仅做概念邻近映射，不包含或复制官方 MBTI 测验。问卷条目为 OML 原创候选条目。

详见 [METHODOLOGY.md](./METHODOLOGY.md)。
